# Design preference study

Anonymous pairwise comparison of visual aesthetics and instruction adherence.

Open the study: https://tony-lowe.github.io/design-preference-study/

The website serves the participant UI and image assets. The deployable Tencent CloudBase answer relay is in [`backend/`](backend/). Browser choices are saved locally and submitted to the relay in the background when a ballot is complete. Administration and exports require the research management key; no key or participant records are stored in this repository.

Images retain their source aspect ratios. All methods use the same viewing and zoom controls. Aesthetic and instruction-adherence judgments are recorded independently.
